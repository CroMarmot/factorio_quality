# 记号、约定与勘误

本项目**唯一维护的文档是 `notebooks/01_quality_theory.ipynb`**（理论正文，三部分：基础转移矩阵 / 纯回收机 / 组装+回收机）。本文件只存放笔记规范性内容：符号表、勘误清单、数值锚点与资料来源。`01-math.md` 为使用者手稿，原样保留。

## 符号约定

全部使用**行向量右乘**：状态为行向量 $x$（$1\times n$），一步演化 $x' = x\,M$，矩阵元 $M_{ij}$ 表示“从等级 $i$ 转移到等级 $j$ 的概率 $\times$ 出入比例”。若使用列向量约定，等价模型为 $x' = M^{\mathsf T} x$，所有矩阵整体转置即可。

叙述一律用 $1$–$5$ 的等级编号（$1$=普通、$2$=优秀、$3$=稀有、$4$=史诗、$5$=传奇，口语“$k$ 星”即等级 $k$）；代码实现里用 $0$-index（$0..4$）与之对应。

| 符号 | 含义 | 维度 |
| --- | --- | --- |
| $i \in \{1,\dots,5\}$ | 品质等级（$L=5$ 为传奇） | 标量 |
| $q$ | 单次制作品质概率（最终 roll 概率），由品质插件叠加：$q=\text{插槽数}\times\text{单插件倍率}$，如 $4\times2.5\%=10\%$ | 标量 |
| $P$ | 总产能加成 = 设备自带（铸造厂、电磁工厂等）+ 产能插件（$50\%$ 即 $P=0.5$） | 标量 |
| $o, i$ | 配方单次产出件数、投入件数 | 标量 |
| $r$ | **出入比例**（产出组数/投入组数，按“一组原料”计，与配方件数无关；组装机 $r=1+P$，回收机固定 $r=\tfrac14$，游戏定值不参数化） | 标量 |
| $Q(q)$ | 品质升级矩阵（Quality 的首字母） | $5\times5$ |
| $M$ | 通用转移矩阵 $\mathrm{diag}(r)\,Q(q)$（第一、二章；行向量右乘 $x' = xM$） | $5\times5$ |
| $A$ | 组装矩阵（Assembling）$\mathrm{diag}(1+P)\,Q(q)$（第三章） | $5\times5$ |
| $R$ | 回收矩阵（Recycle）$\tfrac14\,Q(q)$（不预先清行） | $5\times5$ |
| $C$ | 收集矩阵（Collect）$\mathrm{diag}(0,0,0,0,1)$，$gC$ 取产出中的传奇部分 | $5\times5$ |
| $S$ | 通过掩码 $I-C=\mathrm{diag}(1,1,1,1,0)$ | $5\times5$ |
| $T$ | wiki 的 10 维轮转矩阵（Transition）$\begin{pmatrix}0&A\\SR&0\end{pmatrix}$；主线用 5 维单轮链（$T^2$ 左上角 $ASR$，见 3.2 注） | $10\times10$ |
| $f$ | 材料进料行向量 | $1\times5$ |
| $y$ | 传奇产出向量；组装回收 $fA(I-SRA)^{-1}C$，纯回收机 $fR(I-SR)^{-1}C$ | $1\times5$ |

## 待确认问题与勘误清单

1. **$400\%$ 的表述**：notebook 3.3 将收敛临界小提为“总产能倍率 $1+P < 4$（即 $P<300\%$）”，与 wiki “趋近 $400\%$ 收敛变慢” 对齐；若 wiki 的 $400\%$ 指的是产能**加成**而非倍率，则需改写为 $P<400\%$，请确认。
2. **手稿勘误**（`01-math.md`）：“$p$ 概率升品，则 $9/10(1-p)$ 升 1 品”应为 $9/10\cdot q$（连续升级的几何因子是 $1/10$ 的幂次，不是 $(1-q)$ 的幂次），notebook 1.1.1/1.2.1 已按官方规则修正。
3. **手稿勘误**：总收集式中的 $f(AC + AMRA)$，第二项按语义应为材料收集 $AMRC$（$C$ 为收集矩阵），$AMRA$ 疑为笔误。
4. **转置约定**：手稿写作 $[0,A;R,0]^{\mathsf T}$ 源自列向量约定；行向量右乘下 $T$ 不转置。
5. **收集范围**：wiki 示例同时移出传奇材料与传奇产品；notebook 主线只移出传奇产品（3.2 单轮链）；同时收集的变体未单独展开。
6. **单位归一化（已处理）**：按“一组原料”归一化后，$r$ 为出入比例、与配方件数无关（$1$ 铜块 $\to$ $2$ 铜线的配方 $r$ 仍是 $1$）；组装机 $r_A=1+P$（设备自带产能 + 产能插件），回收机固定 $\tfrac14$（游戏定值，不参数化）。
7. **品质概率定义**：$q$ 取品质插件叠加后的单次 roll 概率（wiki 定义），与游戏内显示值一致；逐行参数 $(q_i, r_i)$ 的电磁工厂式配置留待模拟代码建模。

## 待验证的数值锚点（模拟代码回归目标）

- 纯回收机、回收机品质概率 $q = 10\%$：传奇占比 $0.00693\%$，即约 $14430 : 1$ 的进料比。
- 纯回收机、回收机品质概率 $q = 24.8\%$（$4\times6.2\%$）：传奇占比 $0.03667\%$，即约 $2726.9 : 1$。
- wiki 组装+回收示例（$q=25\%$、产能总量 $50\%$）：稳态行向量 $[\,1.267,\ 0.203,\ 0.083,\ 0.0297,\ 0.0063 \mid 1.426,\ 0.656,\ 0.205,\ 0.073,\ 0.02497\,]$，即一组原料约产出 $2.497\%$ 的传奇产品。
- 收敛临界：总产能倍率逼近 $400\%$（$P \to 300\%$）时 $\theta \to 1$、收敛变慢；超过后发散。
